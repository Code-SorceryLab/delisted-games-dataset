Taxonomy

IDDimensionQuestion answeredValues
  • Unknown (all dimensions): the source data has no evidence for the dimension.
  • N/A (D5): the game has no online component, so there is no service to track.
  • Minor vs. Optional Multiplayer (D4): with Minor, only peripheral services need a connection (news, cosmetics, leaderboards, content sharing). With Optional Multiplayer, the multiplayer modes need a connection, but single-player is fully playable offline.
  • Legacy OS (D6): the hardware is still made, but the game needs a discontinued operating system or runtime (e.g. Adobe Flash, Java applets, Unity Web Player, MS-DOS, Windows 9x) and has no official port to a current one. This value requires the platform field or an explicit statement in the source; speculation about compatibility is not evidence. When the hardware itself is discontinued, Legacy Hardware applies instead.

Classification methods

Each title carries one method, which says how its seven labels were assigned. Manual labels take precedence over the other two methods.

MethodTitlesHow the labels were assigned
Manually reviewed A random sample, stratified by source, labelled by hand by the authors from rule suggestions and annotator notes.
LLM (Claude Haiku) Titles with free text (Dead Game Wiki notes, Delisted Games narratives) or records from several sources. Claude Haiku labelled them from the source data; they are not individually reviewed. On the manually reviewed pilot, Haiku agreed with the human labels on 97–99% of titles per dimension. Each title carries a high, medium or low confidence.
Rules Fixed rules over structured source fields, e.g. Steam Tracker type “Purchase disabled” → D1 = Unavailable. These titles have no free text; dimensions the fields do not cover stay Unknown.

Sources

Event year is the year of delisting, server shutdown or status change reported by the source. See Classification methods for how each label was assigned. "Unknown" means the source data carries no evidence for that dimension; "N/A" means the dimension does not apply. Data and classification are released as a research artifact.
